// dúvidas

Perguntas que você ia fazer.

Precisa saber programar pra usar? +

Não. Skill não é código. É um arquivo de texto que o Claude Code lê pra entender o contexto. Você instala, digita o comando e usa. Se você sabe abrir uma pasta e copiar arquivos, você consegue.

Funciona com qual versão do Claude? +

As skills funcionam com Claude Code (a ferramenta CLI da Anthropic). Você precisa ter uma conta na Anthropic e o Claude Code instalado. As skills são compatíveis com qualquer versão atual: Claude 3, Claude 4 e versões futuras.

O que é uma "alavanca" exatamente? +

É o ponto onde um esforço pequeno gera resultado grande. Em logística pode ser a rota de entrega. Em atendimento pode ser o tempo de primeira resposta. Em vendas pode ser a taxa de follow-up. Toda empresa tem as suas — as skills te ajudam a identificar e agir sobre elas com IA.

Meus dados ficam salvos na nuvem? +

Não. O Claude Code roda na sua máquina. As skills são arquivos locais. O processamento passa pelo modelo da Anthropic (como qualquer uso do Claude), mas você não está mandando dados pra um terceiro adicional. A Anthropic tem política de privacidade própria disponível no site deles.

As skills são atualizadas automaticamente? +

Novas skills são adicionadas ao pacote periodicamente. Quem comprou o acesso recebe as adições sem custo adicional. A atualização não é automática — você baixa o pacote novo quando quiser —, mas o acesso fica com você.

Posso usar em mais de um computador? +

Sim. O acesso é seu. Você pode instalar nas suas máquinas. Não tem DRM, não tem token de ativação. Se quiser compartilhar com o time, temos condições para licenças de equipe — manda um e-mail pra conversar.

E se eu não tiver o Claude Code instalado ainda? +

A instrução de instalação do Claude Code vem junto com o pacote. São 5 minutos: instala o Node, roda um comando no terminal, autentica na Anthropic e pronto. Você não precisa saber nada técnico além de copiar e colar um comando.
